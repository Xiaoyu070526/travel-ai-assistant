## 1. 法律定位与责任边界

### 1.1 服务性质声明

本应用是由华东师范大学学生团队开发的**学术研究型/竞赛原型产品**，旨在探索 AI 辅助入境旅游服务的可行性。核心定位包括：

- **信息整合工具**：聚合公开可查的旅行信息，不构成旅行社、OTA 或专业旅行顾问服务
- **AI 辅助参考**：所有行程建议、攻略内容由大语言模型（LLM）基于训练数据和检索信息生成
- **非商业运营**：当前阶段不收取服务费、不提供票务代理、不处理支付交易

### 1.2 责任限制

| 场景 | 责任声明 |
|------|----------|
| 行程规划建议 | AI 生成的行程仅供参考，用户应根据实际情况独立判断并调整 |
| 票务/预订信息 | 本应用不直接售票，所有预订链接跳转至第三方平台，以平台实时信息为准 |
| 交通路线 | 路线规划基于公开地图数据，实际交通状况（拥堵、封路、班次变更）以现场为准 |
| 政策法规 | 出入境、签证、住宿登记等政策可能随时调整，以官方最新公告为准 |
| 紧急情况 | 涉及人身安全的紧急事件（医疗急救、公共安全、自然灾害），请直接拨打当地紧急电话 |

**核心原则**：本应用提供的信息具有时效局限性，不构成法律、医疗、财务或旅行方面的专业建议。用户基于本应用信息做出的决策及后果，由用户自行承担。

## 2. 数据来源与准确性

### 2.1 数据来源分层

```
┌─────────────────────────────────────────────────────────────┐
│  Tier 1 - 官方权威源（最高可信度）                             │
│  • 中国国家移民管理局（签证政策）                              │
│  • 12306.cn（铁路票务官方）                                   │
│  • 各城市文旅局官网（景点开放时间）                            │
│  • 公安部出入境管理局（住宿登记政策）                          │
├─────────────────────────────────────────────────────────────┤
│  Tier 2 - 平台实时数据（高可信度，需实时核验）                 │
│  • 携程/飞猪/美团（酒店价格、空房状态）                        │
│  • 高德/百度地图（交通路线、POI 信息）                         │
│  • 支付宝/微信支付（绑定流程、限额说明）                       │
├─────────────────────────────────────────────────────────────┤
│  Tier 3 - 知识库与调研（中等可信度，定期更新）                 │
│  • 团队实地调研（2026 年暑期上海/北京/西安实地考察）            │
│  • 外国游客痛点问卷（200 份有效样本）                          │
│  • 公开旅行指南、博客、论坛讨论                                │
├─────────────────────────────────────────────────────────────┤
│  Tier 4 - AI 生成内容（需用户交叉验证）                        │
│  • 大语言模型基于上述数据生成的攻略、建议、对话回复             │
│  • 可能包含模型幻觉（Hallucination），务必通过官方渠道核实      │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 信息时效性

- **静态数据更新周期**：城市基础数据（景点列表、交通指南）每季度核验一次
- **动态数据策略**：价格、空房、班次等动态信息均跳转至第三方平台实时查询，本应用不做缓存
- **AI 知识截止日期**：大语言模型的训练数据存在截止日期，2026 年 10 月后的政策变更可能不在知识库范围内

### 2.3 准确性不保证条款

> ⚠️ **重要提示**：尽管我们尽力确保信息准确，但以下情况可能导致信息偏差：
>
> 1. 大语言模型可能生成看似合理但实际不存在的政策、价格或流程
> 2. 第三方平台数据接口延迟或错误
> 3. 政策突发性调整（如疫情期间的特殊入境政策）
> 4. 地方性执行差异（同一政策在不同城市的执行口径可能不同）
>
> **用户行动建议**：对于涉及签证、入境、住宿登记、票务预订等关键决策，务必通过官方渠道二次确认。

## 3. 隐私与数据处理

### 3.1 数据收集范围

本应用在身份采集环节收集以下信息：

| 字段 | 用途 | 存储方式 | 保留期限 |
|------|------|----------|----------|
| 国籍 | 推荐适配的旅行方案 | 浏览器 Session（内存） | 会话结束即清除 |
| 到达日期 | 计算行前准备时间线 | 浏览器 Session（内存） | 会话结束即清除 |
| 中文水平 | 调整信息呈现复杂度 | 浏览器 Session（内存） | 会话结束即清除 |
| 语言偏好 | 界面语言和 AI 输出语言 | 浏览器 Session（内存） | 会话结束即清除 |
| 是否有中国手机号 | 判断预订可行性 | 浏览器 Session（内存） | 会话结束即清除 |

### 3.2 数据不收集声明

**以下信息本应用明确不收集、不存储、不传输**：

- ❌ 真实姓名、护照号码、身份证号
- ❌ 银行卡号、支付密码
- ❌ 精确地理位置（GPS 坐标）
- ❌ 生物识别信息（指纹、人脸）
- ❌ 聊天记录持久化存储（会话结束即清除）

### 3.3 第三方服务交互

当使用以下功能时，数据将传输至对应第三方服务：

| 功能 | 第三方服务 | 传输数据 | 隐私政策 |
|------|-----------|----------|----------|
| AI 对话 | DeepSeek | 用户问题 + 旅行上下文 | 以各服务商隐私政策为准 |
| 地图展示 | 高德地图 API | 城市名称、POI 查询 | 高德隐私政策 |
| 票务跳转 | 携程 / 12306 | 无数据直传，仅浏览器跳转 | 以平台隐私政策为准 |

### 3.4 Cookie 与本地存储

- 本应用使用浏览器 Session Storage 保存用户的旅行偏好设置
- 不使用 Cookie 进行用户追踪或广告投放
- 不向第三方出售或共享任何用户数据
