### 3. 关键审校结论
| 审校项 | 结论 | 说明 |
|--------|------|------|
| 英文文案 | ✅ 可看懂 | 以简洁指令式英文为主，面向非中文游客 |
| 默认语言 | en | 未采集身份时默认英语，匹配 "不会中文的美国游客" 演示场景 |
| 回退安全 | ✅ 不抛异常 | `t()` 缺失语言 → 回退 en；缺失 key → 原样返回 key |
| 专有名词 | 保留中文拼音 | 如 "Alipay", "WeChat", "12306" —— 国际通用 |
| 价格/时间 | 保留数字 + 单位 | "¥100", "3 days" —— 无歧义 |
